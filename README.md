# BizGen — Business Generation Tool v2.0

Полностью автономный офлайн-инструмент для генерации бизнес-идей, расчёта юнит-экономики, управления запусками и безопасного хранения данных.  
Работает в любом современном браузере без сервера, без интернета, без регистрации.

## Возможности (12 модулей)

- **🏗 Business Constructor** — генератор бизнес-модели по типу, проблеме, клиенту. Выдаёт блюпринт, оценки TAM, CAC, целевого дохода.
- **👤 Freelancer Simulator** — расчёт ставок, загрузки, чистого дохода для 8 профессий.
- **🔌 Integration Hub** — каталог из 24 интеграций (CRM, платежи, аналитика) с переключателями статуса.
- **🔒 Backup Encryptor** — AES‑GCM 256‑битное шифрование (PBKDF2, 100k итераций) локальных данных. Ничего не покидает браузер.
- **🧪 Module Tester** — автотестирование 15+ параметров системы + ручные проверки.
- **✅ Offline Checklist** — чеклист из 12 шагов для запуска бизнеса с сохранением прогресса.
- **📝 Notes** — автосохранение заметок с быстрыми тегами.
- **💰 Passive Income Tracker** — учёт пассивных источников дохода.
- **📚 Instruction Library** — 75 промптов‑инструкций по маркетингу, продажам, продукту, финансам, росту (Premium).
- **🌐 Emergence Table** — анализ 5 эмерджентных свойств бизнес-системы.
- **🚀 One‑Move Launch** — 14 конкретных идей для быстрого старта с оценкой усилий и дохода.
- **⚠ LLM Limitations Report** — 10‑секционный отчёт об ограничениях языковых моделей для безопасного применения в бизнесе.

## Как использовать

1. Скачайте файл `index.html` (единственный файл).
2. Откройте его в Chrome, Firefox, Safari или Edge.
3. Все данные сохраняются локально в вашем браузере.

Для активации Premium (полная библиотека и шифрование) нажмите **🔑 Licence** и введите ключ `BIZGEN-DEMO-2024`.
